📌 CÁCH MỞ TRANG WEB:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Tìm file "index.html" trong thư mục
2. Nhấp đúp vào file đó
3. Trang web sẽ tự động mở trong trình duyệt
4. Hoặc kéo thả file vào trình duyệt Chrome/Edge/Firefox

🎯 CÁC TÍNH NĂNG CHÍNH:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 1. QUẢN LÝ CÔNG VIỆC
   - Nhập công việc → Nhấn "Thêm"
   - 🔍 Tìm kiếm công việc theo tên, phân loại, trạng thái
   - Nhấn "✓ Hoàn thành" khi làm xong
   - Nhấn "🗑️ Xóa" để xóa công việc (có xác nhận)
   - Cảnh báo deadline: màu cam (sắp hết hạn), đỏ (quá hạn)

🎯 2. QUẢN LÝ MỤC TIÊU
   - Nhập mục tiêu và các bước cần làm
   - Theo dõi tiến độ hoàn thành
   - Đính kèm link liên quan

⚙️ 3. CÀI ĐẶT TÙY CHỈNH
   - Thay đổi ảnh đại diện
   - Thêm/xóa phân loại công việc
   - Thêm/xóa trạng thái tiến độ

⌨️ 4. PHÍM TẮT KEYBOARD:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Ctrl + N: Tạo công việc mới
- Ctrl + S: Lưu dữ liệu
- Ctrl + E: Xuất dữ liệu
- Escape: Đóng modal
- Phím 1, 2, 3: Chuyển tab

💾 5. QUẢN LÝ DỮ LIỆU:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Tự động lưu vào localStorage của trình duyệt
- Xuất dữ liệu ra file JSON
- Nhập dữ liệu từ file JSON
- 🔍 Kiểm tra trạng thái lưu trữ
