# Personal Task Manager

A modern, responsive web application for managing personal tasks and goals with professional UI and advanced features.

## 🌟 Live Demo

[View Live Demo](https://your-username.github.io/personal-task-manager)

## ✨ Key Features

- 🎯 **Task & Goal Management** - Create, track, and organize your tasks and goals
- 🔍 **Smart Search** - Find tasks instantly by name, category, or status  
- ⌨️ **Keyboard Shortcuts** - Work faster with Ctrl+N, Ctrl+S, Ctrl+E shortcuts
- 📱 **Responsive Design** - Works perfectly on desktop and mobile
- 🔒 **Secure & Private** - All data stored locally in your browser
- 🎨 **Modern UI** - Professional blue theme with smooth animations
- ♿ **Accessible** - Built with accessibility best practices
- 🌍 **Location Aware** - Automatic location detection
- 📊 **Data Export/Import** - Backup and restore your data

## 🔧 Customization

The app is highly customizable through CSS variables:

```css
:root {
    --primary-blue: #005B96;    /* Main brand color */
    --primary-orange: #FF7A00;  /* Accent color */
    --success-color: #28a745;   /* Success states */
    --warning-color: #ffc107;   /* Warning states */
    --danger-color: #dc3545;    /* Error states */
}
```
